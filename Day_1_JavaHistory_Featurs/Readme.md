# ☕ Day 01 - Java History and Features

## Java History

Java was developed by James Gosling and his team at Sun Microsystems.

Initial Name:
Oak

Reason for changing:
Oak name already existed.

New Name:
Java

Release Year:
1995

Main slogan:

Write Once Run Anywhere (WORA)

Meaning:

Java code can run on any system having JVM.

Flow:

Java Program
↓
Compiler (javac)
↓
Bytecode
↓
JVM
↓
Output

---

## Features of Java

### 1. Simple

Easy syntax and easy to learn.

Example:

```java
System.out.println("Hello");
```

### 2. Platform Independent

Write code once and run anywhere.

Windows
Linux
Mac

### 3. Object Oriented

Uses:

Class
Object
Inheritance
Polymorphism

### 4. Secure

No pointer concept.

### 5. Robust

Strong memory management.

### 6. Portable

Runs on multiple systems.

### 7. Multithreaded

Can perform multiple tasks simultaneously.

Example:

Downloading + Music simultaneously
